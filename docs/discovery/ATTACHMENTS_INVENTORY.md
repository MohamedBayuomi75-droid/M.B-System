## 3. على السيرفر
| البند | الحالة |
|---|---|
| التخزين | جوه PostgreSQL (جدول `attachments`، ADR-007/ADR-014)، بـ SHA-256 وحجم ونوع وسجل مالك |
| الإصدارات | `replaces=<id>`: الإصدار القديم بيتعلّم «متبدّل» ومابيتمسحش (المرحلة 5) |
| الفحص | النوع من المحتوى، والحجم لحد 25 MB، ورفض الملفات التنفيذية والماكرو وPDF بـ JavaScript. **PDF المشفّر: B-78 (أ)، لسه ماتنفّذش** |
| الحجم بعد التحميل | 108 مرفق = 6.9 MB جوه قاعدة 22 MB (المرحلة 2) |
| البديل المعتمد لو الحجم كبر | نظام الملفات على السيرفر + بيانات وصفية في PostgreSQL (`01` §4)، **بقرار صريح بس** |

## 4. اللي محتاج يتعمل قبل ترحيل المرفقات
1. **تنفيذ B-78 (أ)** في فاحص الملفات + اختبارات (PDF مشفّر بكلمة سر فارغة ← مقبول بعد الفحص؛ PDF بكلمة سر فتح ← مرفوض).
2. **الـ 115 اسم من غير مسار:** نحدّد لكل واحد هل ليه ملف (بالبحث بالاسم في فولدر المرفقات)، ولا يتسجّل «مرجع من غير ملف». **من غير أي تعديل في السجل الأصلي** (`04` §11).
3. **المرجع الناقص (1):** يتسجّل في سجل الحجر (Quarantine) لحد ما يتلاقى الملف أو يتقرر.
4. ترحيل بـ checksum لكل ملف + تقرير الملفات اليتيمة (`04` §10.4).
