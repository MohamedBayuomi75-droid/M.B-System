# توحيد أعمق — 1.1.0

## ما تغيّر
1. **الهوية**: شعار فرعي واحد يذكر كل الركائز (HR · موردون · عملاء · مخازن · حسابات)
2. **التنقل**: أسماء أقسام أقصر وأوضح (المتابعة، الموارد البشرية، العملاء والمشاريع، الأرشيف، الإعدادات)
3. **الثيم**: `--accent` موحّد = لون النظام؛ فلاتر `filters-row` / `filters-bar` لكل الأقسام
4. **رؤوس الصفحات**: `unifiedPageHeader` + `unifiedStatsRow` لاستخدام موحّد
5. **مسار المشروع**: classes موحّدة `.project-path-chip`
6. **body[data-section]**: لتمييز القسم الحالي بدون تطبيقات منفصلة
7. **الإعدادات** (من 1.0.2): تبويبات الموردين + العملاء + المخازن داخل نفس الصفحة

## فلسفة التوحيد
- تطبيق Electron واحد · ملف بيانات واحد · شريط تنقل واحد · إعدادات واحدة · ثيم واحد
- البادئات البرمجية (lg*) عزل أسماء داخلية فقط وليست حدود منتج
