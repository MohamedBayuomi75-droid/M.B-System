## المرتجعات
صفحة «الفواتير» بقت فواتير بس، و«المرتجعات» صفحة لوحدها (مرتجعات بس). نفس البيانات ونفس النماذج؛ اتأكدنا إن صفوف الصفحتين مطابقة لصفحة الفواتير الأصلية
بعد فلتر النوع (فواتير/مرتجعات)، وإن مجموع الاتنين = كل السجلات (588 + 46 = 634 على بياناتك). فلاتر الصفحتين ما بتتسرّبش لبعض.

## إضافة صفحة جديدة
1. أضفها في قسمها في `NAV_SECTIONS` (مفتاح بادئته مصدرها: `ledger.` / `clients.` / `warehouses.` / `accounts.` / `tasks.` / `general.`).
2. لو لسه مش جاهزة: أضفها في `PLACEHOLDER_PAGES` (برقم الإصدار). لو جاهزة: اربطها في `renderCurrentPage` (أو `renderLedgerPage` لصفحات الدفتر).
3. أضف مفتاحها في `HR_PAGES` (`permissions.js`) وتسميتها في مصفوفة المستخدمين (`pages-users.js`).
4. `npm run check` بيتأكد من ده كله.
