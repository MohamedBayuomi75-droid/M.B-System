# المكتبات المحلية (vendor)

> المكتبات اللي بتتحمّل من داخل المشروع نفسه، **من غير CDN وقت التشغيل**.
> أي تحديث لازم يتسجّل هنا بالمصدر والإصدار والبصمة، والاختبار `npm test` بيتأكد إن الملف مطابق للبصمة.

## `vendor/xlsx.full.min.js` — SheetJS (استيراد وتصدير Excel)

| البند | القيمة |
|---|---|
| الإصدار | **0.20.3** (آخر إصدار رسمي وقت التحقق، 2026-11-17) |
| المصدر الرسمي | `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js` — موجود كمان داخل الحزمة `https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz` |
| SHA-256 للملف | `cc015130aa8521e7f088f88898eba949ccdcbfb38df0bd129b44b7273c3a6f41` |
| SHA-256 للحزمة (`.tgz`) | `8dc73fc3b00203e72d176e85b50938627c7b086e607c682e8d3c22c02bb99fe8` |
| الحجم | 951,904 بايت |
| الثغرات المصلَّحة | CVE-2023-30533 (Prototype Pollution — اتصلّحت في 0.19.3) · CVE-2024-22363 (ReDoS — اتصلّحت في 0.20.2) |
| الترخيص | Apache-2.0 (الملف `LICENSE` داخل الحزمة الرسمية) |

**طريقة التحقق (2026-11-17):**
1. نزّلت الحزمة والملف المباشر من cdn.sheetjs.com.
2. الملف اللي جوه الحزمة مطابق للملف المباشر بايت ببايت (`cmp`).
3. `XLSX.version` بعد التحميل = `0.20.3`.
4. **ملف `vendor/xlsx.full.min.js` اللي في المشروع كان مطابق بالفعل للملف الرسمي** (نفس البصمة)، فماحتاجش يتبدّل.

> ملاحظة: تقرير الفحص القديم (`SECURITY_AUDIT.md` S8) قال إن 0.18.5 بتتحمّل في المتصفح، وده كان غلط.

**التغيير اللي اتعمل فعلًا:**

النسخة اللي فيها الثغرات كانت اعتماد npm `"xlsx": "^0.18.5"` في `package.json`. برنامج الديسكتوب (`src/main/excel.js`) كان بيجرّبها **قبل** نسخة vendor، وnpm مافيهوش أي إصدار مصلَّح. فعملت الآتي:
- شلت الاعتماد من `package.json`.
- `src/main/excel.js` بقى يحمّل `vendor/xlsx.full.min.js` بس، ومابيجرّبش `node_modules` خالص، عشان أي نسخة قديمة متبقية على جهاز ماتتحمّلش بالغلط.
- نسخة الويب (`web/index.html`) بتحمّل نفس الملف المحلي `vendor/xlsx.full.min.js`، ومن غير CDN.

**الاختبارات:**
- `npm test`: 14 فحص.
  - البصمة.
  - مفيش اعتماد npm.
  - مفيش CDN في الويب.
  - الإصدار ≥ 0.20.2 في الديسكتوب.
  - تصدير ثم استيراد حقيقي بالعربي والأرقام (4 خانات) والرموز.
  - CSV بـ BOM.
  - ملف تالف.
  - ملف مصمَّم بـ `__proto__` مايلوّثش `Object.prototype`.
  - الإلغاء.
- `tests-merge/phase60.js` (الوضعين): من شاشة «استيراد من إكسيل» في دفتر الموردين: ملف حقيقي ← موردين جداد بالقيم الصح ← محفوظين على السيرفر (وضع الويب) ← تصدير لملف حقيقي ← قراءة الملف والتحقق منه.

**طريقة التحديث في المستقبل:**
1. نزّل الإصدار الجديد من cdn.sheetjs.com بس (npm مش بيتحدّث).
2. قارن الملف المباشر بنسخة الحزمة.
3. حدّث الجدول ده و`EXPECTED_SHA256` في `tools/test-security.js`.
4. شغّل `npm test` و`npm run test:ui` و`npm run test:ui:web`.
