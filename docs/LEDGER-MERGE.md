# دمج دفتر الموردين — دمج حقيقي (0.5.0)

دفتر الموردين بقى **جزء من نفس البرنامج**: نفس النافذة، نفس الإعدادات والمستخدمين والنسخ الاحتياطي، ونفس ملف البيانات.
(الإصدار 0.3.0 كان بيشغّل الدفتر في إطار iframe؛ اتشال بالكامل.)

## فين كل حاجة
| الموضوع | المكان |
|---|---|
| القائمة والصفحات | صفحات الدفتر (9 مفاتيح `ledger.*` منها `ledger.returns`) موزّعة على أقسام التنقل حسب تصميم المستخدم (الموردون، الحسابات، التقارير، الأرشيف، الإعدادات…) — `core/modules.js` و`docs/NAVIGATION.md` |
| كود الدفتر | `renderer/modules/ledger/*.js` (مولَّد بالـ codemod من البرنامج الأصلي — راجع `tools/merge/README.md`) |
| الربط بالإطار | `renderer/modules/ledger/glue.js` (يدوي): الرسم، دورة البيانات، الاستيراد، تبويب الإعدادات |
| بيانات الموردين | `DATA.ledger` (موردين، فواتير، دفعات، قوائم الاقتراحات، مجلدات الأرشيف وسلتها، أنواع المستندات) |
| إعدادات الدفتر | في **إعدادات البرنامج الموحّد** (`DATA.settings`): اسم الشركة، مدير الشركة (`companyManager`)، `moneyDecimals`، `nextPaymentNo`. وتبويب «الموردون والفواتير» في صفحة الإعدادات |
| سجل العمليات | سجل التدقيق الموحّد `DATA.auditLog` |
| المستخدمون والصلاحيات | نظام HR. صفحات الدفتر في المصفوفة (`ledger.*`)؛ مستخدم محفوظ قبل الدمج ومفيش عنده مفاتيح الدفتر → مرفوض (الأدمن بس) |
| النسخ الاحتياطي / التحديث / الشبكة | HR (الملف الواحد بيشمل `ledger`) |
| CSS | `modules/ledger/ledger.css`: قواعد الدفتر الجديدة + المختلفة محصورة في `body.module-ledger` |

## قواعد الأسماء
52 اسم عام كان متصادم بين الدفتر وHR اتغيّر في كود الدفتر لبادئة `lg` (مثلاً `render`→`lgRender`، `currentPage`→`lgCurrentPage`،
`fmtDate`→`lgFmtDate`). القائمة كاملة في `tools/merge/rename-map.json`. `npm run check` بيمنع أي تصادم جديد.
قاعدة التعامل مع الكود الجديد: اسم عام جديد في الدفتر → ما يبقاش موجود في باقي البرنامج.

## نقاط الربط في باقي البرنامج
- `core/app.js`: `renderCurrentPage` (فرع الدفتر)، `attachPageHandlers` (نطاق `module-ledger` + `lgAfterRender`).
- `core/data-store.js`: ترحيل schema 4 (`lgMigrateLegacySection`)، وخطافات `lgOnDataLoaded` / `lgOnBeforeSave`.
- `core/pages-backup.js`: تبويب الإعدادات (`lgRenderSettingsPanel` / `lgInitSettingsPanel`).
- `core/permissions.js` + `pages-users.js`: صفحات الدفتر في المصفوفة.

## استيراد بيانات الدفتر القديم
الإعدادات ← «الموردون والفواتير» ← «استيراد بيانات دفتر الموردين القديمة (data.json)». بيتأخذ نسخة احتياطية الأول. إعدادات الملف القديم بتتدمج في إعدادات
البرنامج (من غير ما تمسح قيم موجودة)، وسجل عملياته بيتدمج في سجل التدقيق، وحسابات مستخدميه القديمة بتتجاهل.
ملفات 0.3.0 (اللي كان فيها `settings` و`auditLog` جوه قسم `ledger`) بتتحول تلقائياً عند أول تشغيل (schema 4).
