**تفاصيل 5.6 (محرك الاعتمادات):**
- أنواع مستندات ومسارات بنُسخ ونطاقات قيمة.
- مستويات ALL / ANY / N_OF_M، والمعتمد دور أو مستخدم.
- لقطة وقت الإرسال، وسجل قرارات وحالات إلحاق فقط.
- سحب وإلغاء وإرجاع، والسبب إلزامي.
- شاشة «بانتظار اعتمادي».
- فصل المهام إعداد **إلزامي** في كل مسار.

**تفاصيل 5.7 (ترقيم NO_GAPS):**
- عدّاد مقفول داخل معاملة المستند، وسجل أرقام محمي بـ trigger: مفيش حذف ولا تعديل، غير «صادر ← ملغى».
- فحص فجوات على `GET /api/v1/numbering/:scope/audit`.
