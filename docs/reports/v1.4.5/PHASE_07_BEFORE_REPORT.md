## أ. قواعد المرحلة (من الخطة)
- **موديول واحد في كل حزمة عمل.** كل موديول بيمشي بنفس الـ 12 خطوة اللي مشى بيها الموردين والعملاء:
  - النطاق ← الاستكشاف ← الجداول والربط ← السيرفر ← الشاشة بنفس شكل القديمة.
  - ← الصلاحيات والتدقيق ← الاختبارات ← نقل تجريبي ومطابقة ← UAT.
  - ← بروفة نقل ورجوع ← **موافقتك** ← النقل الفعلي (في المرحلة 13).
- **المستندات التشغيلية والأرصدة التشغيلية بس.** مفيش قيود يومية ولا إقفال فترات. ده المرحلة 10.
- **قبل الفواتير والدفعات والتحصيلات:** لازم **عقود الواجهة مع المحاسبة** تتكتب وتتعتمد الأول: حالات المستند، والمبالغ، والأطراف، والمشروع، والضرايب، ومفاتيح الـ idempotency.
- **معيار الشكل اللي اتعلّمناه (DEC-0093):** أي شاشة جديدة بتلبس CSS الواجهة القديمة نفسه، وبتتقارن بيها جنب بعض **قبل** الـ UAT.

## ج. المقترح
1. **الحزمة 7.1: المخازن** (المرشح 1).
   - **النطاق:** الشاشة بشكل القديمة (نفس طريقة الموردين والعملاء)، والتتبّع، ومصفوفة الحقول، واختبارات P0 الناقصة، وUAT، وبروفة نقل ورجوع.
   - **التكلفة والتقييم برا النطاق** لحد B-20 وB-77.
   - **ليه هي:**
     - مبنية فعلًا.
     - مفيش بيانات حقيقية، فالنقل مخاطرته قليلة.
     - بتقفل موديول تاني بنفس الطريقة المعتمدة.
2. **بالتوازي، من غير كود: تجهيز قرارات الفواتير.** بجهّز لك مستند قرار فيه:
   - **B-27:** العملات.
   - **B-29:** نطاق الترقيم وشكله.
   - **قاعدة رصيد المورد:** معتمدة (F-05). المستند بيوضّح أثرها بالأرقام، واعتماد الأرصدة الافتتاحية وقايمة B-53.
   - **مسودة عقود الواجهة مع المحاسبة.**

   عشان الحزمة 7.2 (فواتير الموردين) تبدأ وهي مش مستنية حاجة.
