# تقرير ما قبل الحزمة 8.3 — الموظفين (خطة v1.4.5، المرحلة 8)

> **المرجع:** `PHASE_08_BEFORE_REPORT.md` (DEC-0121)، و`PHASE_08_2_AFTER_REPORT.md` (DEC-0124).
> **التاريخ:** 2026-11-24 · **الحالة:** **مطلوب موافقتك قبل أي تنفيذ.**

## أ. الملخص
- **الموظفين آخر نوع أشخاص** في المرحلة 8: **40 موظف حقيقي**، و34 حقل (ومنهم البريد، ونوع التوظيف، ورصيد الإجازات).
- **الأدوات جاهزة من 8.1 و8.2:** القوايم واللوحات والكروت والملاحظات، وأرشيف المستقيلين، ومنع التكرار، وتخطيط الأعمدة، وترتيب خانات النوافذ، والجداول والنقل.
- **الجديد هنا:**
  - **قسم المستقيلين في صفحة الموظفين ليه جدول وكروت وفلاتر خاصة** (`resignedEmployeesTableHtml`)، مش زي باقي الأنواع.
  - **نافذة الموظف** فيها البريد، ونوع التوظيف، ورصيد الإجازات.
  - **الإجازات صفحة لوحدها لكل الأنواع**، فيها طلب ← موافقة أو رفض، ورصيد، وطباعة. والإجازة المعتمدة السارية بتغيّر حالة الشخص لـ «في إجازة» في كل الصفحات (`syncLeaveStatuses`). **البيانات الحقيقية فيها إجازة واحدة بس.**
