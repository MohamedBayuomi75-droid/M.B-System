## 2. القرار والتنفيذ — DEC-0093 (أ) تطابق كامل (2026-11-20)
**الطريقة:** بدل تقليد الشكل، الشاشات الجديدة **بتلبس CSS الواجهة القديمة نفسه**:
- `tools/ui/build-legacy-skin.js` بياخد `style.css` و`ledger.css` والـ CSS اللي `app.js` بيحقنه، ويحصرهم في `.lx-root` و`.lx` عشان مايأثروش على باقي صفحات Angular. وبيطلّع كمان أقسام التنقل من `modules.js`.
- المخرجات مولَّدة (`frontend/src/legacy-skin.css` و`frontend/src/app/core/legacy-nav.ts`)، ومتشيّكة في الـ CI. **أي تعديل في شكل القديمة بيتنقل للجديدة بإعادة التوليد.**
- القوالب بنفس عناصر الواجهة القديمة وكلاساتها وترتيبها (`renderSuppliersPage` و`renderInfoTab` و`openAddSupplierModal` و`renderClientsCustomersPage` و`openCustomerModal`).
