# مقارنة الشكل: الواجهة القديمة ↔ الجديدة — الموردين والعملاء (خطة v1.4.5 — `04` §4.3)

> **السبب:** ملاحظة المستخدم في الـ UAT (2026-11-20): «شكل الواجهة الجديدة مختلف عن القديمة». الخطة بتطلب «Angular screens with visual parity» (`02` Phase 6)، وبتقول **ماينفعش شكل Angular Material الافتراضي يحل محل الواجهة الحالية من غير موافقة** (`04` §4.2)، وكل فرق يتسجّل ويتصنّف، والفرق اللي مش متوافق عليه يتصلّح قبل القبول (`04` §4.3).
> **المقارنة دي ماتعملتش قبل الـ UAT. ده تقصير، واتسجّل هنا.**
> **اللقطات:** نفس المقاس (1366×768) وبيانات مُركّبة، القديمة يمين والجديدة شمال: `docs/reports/v1.4.5/phase6-visual/` (`suppliers-list`، `suppliers-form`، `customers-list`، `customers-form`).

## 3. تأثيرها على القبول
- **بُعد «تطابق الشكل والوظايف» (2) بقى Red** لحد التنفيذ (`PARTIES_ACCEPTANCE.md` §7). والـ Red بيمنع القبول.
- **البروفة (P6-D) ناجحة ومش محتاجة تتعاد**: التغيير في الواجهة بس، والـ API والجداول والنقل زي ما هم.
- **الـ UAT:** نتايجه الحالية بتتسجّل كما هي. وبعد التنفيذ بيتعمل **UAT للشكل** على الشاشتين (سيناريوهات مقارنة قديم ↔ جديد).
