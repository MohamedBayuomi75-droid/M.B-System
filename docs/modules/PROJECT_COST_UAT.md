# سيناريوهات القبول — التكاليف وتكلفة المشروع (خطة v1.4.5 — المرحلة 8، الحزمة 8.8) — ضمن البروفة المجمّعة

> على النسخة المعزولة بس، وبتكاليف اصطناعية على شخص ومشروع «تجريبي». **مفيش تكلفة حقيقية بتتعدّل أو تتمسح.** بصمة كل سجل حقيقي قبل وبعد.
> التكلفة في الجديدة **بالحساب الجديد (TR-10، DEC-0142)** — الاختلاف عن القديمة متوقع بس في المصروف بسطور، والفاتورة اللي فيها مخصوم، واليوميات اللي فيها تقريب أو مستنية مراجعة، ويوميات المعدات توقف / نقل / تكلفة إضافية.
