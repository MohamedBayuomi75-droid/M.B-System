# خطة معالجة البيانات والفروق المالية — **للموافقة، مفيش حاجة منها اتنفذت**

- **التاريخ:** 2026-11-17 · **المرحلة:** بعد قرارات المرحلة 3.
- **البيانات:** نسخة `data.json` الحقيقية (v1.3.53). القياس اتعمل عليها **قراءة بس**، وبرّه المستودع.
- **الأداة:** `tools/formulas/target-diff.js`. بتطلّع الملخص ده، وبتطلّع **قوائم مراجعة تفصيلية** فيها المعرّفات (مكانها برّه المستودع، وممنوع ترفع لأنها بيانات حقيقية).
- **القواعد:** `TARGET_BUSINESS_RULES.md`.

> **ولا حاجة في الخطة دي هتتنفذ من غير موافقتك.** كل بند ليه موافقة منفصلة. التنفيذ بيحصل وقت ترحيل الموديول بتاعه (المرحلة 6)، **على نسخة**، وبعد نسخة احتياطية اتجرّبت استعادتها.
