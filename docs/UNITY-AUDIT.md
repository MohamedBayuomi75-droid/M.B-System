# مراجعة التوحيد — 1.0.2

## ما يجعله نظاماً واحداً (وليس برامج ملصوقة)

1. **ملف بيانات واحد** `DATA` يحفظ عبر نفس `saveData()`:
   - HR على المستوى الأعلى (employees, projects, …)
   - `DATA.ledger` للموردين
   - `DATA.clients` للعملاء
   - `DATA.warehouses` للمخازن
2. **تنقل واحد** (NAV_SECTIONS) + صلاحيات واحدة (permissions matrix)
3. **إعدادات واحدة** صفحة backup/settings بتبويبات:
   الشركة · الأمان · النسخ · الاستيراد · الموردون · العملاء · المخازن · التخزين · …
4. **نسخة احتياطية واحدة** = JSON.stringify(DATA) بالكامل
5. **مظهر واحد** style.css + نفس مكونات (page, table, modal, stats)
6. **جسور بيانات**: مشاريع العملاء تُزامَن لـ DATA.projects؛ استلام المخزن يرتبط بفواتير الموردين؛ الصرف يرتبط بالمشاريع

## بقايا تقنية (طبيعية بعد الدمج، لا تعني برنامجين منفصلين)

- بادئة `lg*` لدوال الموردين (عزل أسماء لتجنب التعارض) — نفس التطبيق ونفس DATA
- `ledger.css` مكمل لنفس الثيم
- لوحات إعدادات فرعية داخل نفس صفحة الإعدادات (تبويبات) وليست نوافذ برامج منفصلة

## الإعدادات تغطي
| تبويب | المحتوى |
|---|---|
| الشركة | اسم، عنوان، مدير، ضريبي… لكل النظام |
| الأمان | PIN ووضع القراءة فقط |
| النسخ الاحتياطي | تصدير/استيراد JSON كامل |
| الاستيراد والتصدير | Excel HR + استيراد عملاء قديم + تصديرات |
| الموردون | أرقام عشرية، استيراد دفتر قديم، فحص |
| العملاء | بادئات الترقيم، تصنيفات، استيراد |
| المخازن | بادئات، مخزن افتراضي |
| الشبكة / التدقيق / الخطر | على مستوى النظام |
